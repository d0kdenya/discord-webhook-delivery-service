# Discord Webhook Delivery Service

Сервис для асинхронной и надёжной доставки Discord webhook-ов.

В качестве очереди используется BullMQ, состояние очередей хранится в Redis.

## Стек

- Node.js
- NestJS
- TypeScript
- BullMQ
- Redis
- Docker / Docker Compose

## Что делает сервис

Сервис:

- принимает webhook-события через HTTP;
- складывает их в очередь;
- отправляет webhook-и в Discord асинхронно;
- ограничивает отправку максимум до 2 webhook в секунду на каждый канал;
- обрабатывает каналы независимо друг от друга;
- повторяет временные ошибки;
- отдельно обрабатывает `429 Too Many Requests`;
- отправляет невосстановимые ошибки в DLQ.

## Быстрый запуск

### 1. Установить зависимости

```bash
npm install
```

### 2. Создать `.env`

Создайте файл `.env` в корне проекта.

Можно скопировать `.env.example`.

После этого заполните реальные Discord webhook URL.

### 3. Запустить Redis через Docker

```bash
docker compose up -d
```

Проверить, что контейнер запущен:

```bash
docker ps
```

### 4. Запустить приложение

```bash
npm run start:dev
```
